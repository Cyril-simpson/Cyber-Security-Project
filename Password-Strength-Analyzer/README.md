# Password Strength Analyzer

## Project Description

Password Strength Analyzer is a Python-based cybersecurity project
that checks the strength of user-generated passwords.

## Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Provides password strength
- Provides suggestions for improving weak passwords

## Technologies Used

- Python
- Regular Expressions (Regex)

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

python password_analyzer.py

5. Enter a test password when prompted.

## Learning Outcomes

- Understanding basic password security principles
- Using regular expressions
- Input validation
- Creating user-friendly security feedback

## Disclaimer

This project is created for educational purposes.
Do not enter real or sensitive passwords.
