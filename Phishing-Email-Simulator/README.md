# Phishing Email Awareness Simulator

## Project Description

This project is an educational cybersecurity application that
helps users recognize common phishing email warning signs.

The program displays fictional email examples and asks the
user to identify whether each message is phishing or safe.

## Features

- Displays fictional email scenarios
- Identifies phishing warning signs
- Provides immediate feedback
- Calculates the user's score
- Provides cybersecurity awareness training

## Technologies Used

- Python
- Random module

## How to Run

Run the following command:

python phishing_simulator.py

Then read each fictional email and select:

1. Phishing
2. Safe

## Learning Outcomes

- Understand common phishing techniques
- Recognize suspicious email patterns
- Understand social engineering risks
- Improve phishing awareness

## Safety

This project is an educational simulation.

It does not send emails, collect passwords,
collect credentials, or target real users.
