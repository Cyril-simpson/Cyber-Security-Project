# Data Encryption and Decryption Tool

## Project Description

This project is a Python-based cybersecurity tool that demonstrates
encryption and decryption using AES and RSA algorithms.

## Objectives

- Understand data confidentiality
- Demonstrate symmetric encryption
- Demonstrate asymmetric encryption
- Perform encryption and decryption
- Understand basic cryptographic concepts

## Features

- AES-256 encryption and decryption
- RSA-2048 encryption and decryption
- User-friendly command-line interface
- Automatic key generation
- Base64 representation of encrypted data

## Technologies Used

- Python
- Cryptography library
- AES
- RSA
- OAEP
- SHA-256

## Algorithms

### AES

AES is a symmetric encryption algorithm.

The same secret key is used for encryption and decryption.

### RSA

RSA is an asymmetric encryption algorithm.

It uses two keys:

- Public key
- Private key

The public key is used for encryption and the private key is
used for decryption.

## How to Run

Install the required library:

pip install -r requirements.txt

Then run:

python encryption_tool.py

Choose AES or RSA and enter a test message.
